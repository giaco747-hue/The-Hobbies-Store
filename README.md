## Project Overview

**The Hobbies Store** is a front-end website project focused on radio-controlled (RC) hobbies and vehicles. It presents different product and hobby categories through a multi-page website, with a visual identity built around a red-and-black color palette and a retro-inspired style.

The website was developed as part of the **Desarrollo Web Flex** course.

## Technologies

The project uses the following front-end technologies and tools:

- **HTML5** — structures the website's pages and content.
- **CSS3** — controls layout, presentation, and responsive styling.
- **Sass / SCSS** — supports a more organized styling workflow through SCSS source files.
- **Bootstrap** — provides front-end layout and styling utilities where used.
- **JavaScript** — supports client-side behavior through `script.js`.
- **Google Fonts** — includes the Honk typeface as part of the visual identity.

## Website Sections

The project is organized around these pages:

- **Home (`index.html`)** — the main entry point.
- **Gallery (`galeria.html`)** — a gallery of RC hobby-related content.
- **Airplanes (`aviones.html`)** — the RC airplane category.
- **Drones (`Drones.html`)** — the drone category.
- **Cars (`carros.html`)** — the RC car category.
- **Tanks (`Tanques.html`)** — the RC tank category.

## Design and Visual Identity

The website follows a distinctive visual direction:

- A red-and-black color palette.
- A retro-inspired presentation.
- Typography that includes the Honk font.
- Content centered on RC vehicles and model-hobby interests.
- A multi-page structure that separates the different hobby categories.

## Styling Workflow

The project includes both `scss/` and `css/` folders. SCSS is the source format used to organize styles, while the browser uses compiled CSS files.

When making style changes, edit the relevant `.scss` source file and compile it to CSS if that is the workflow configured in the project. Make sure the compiled stylesheet referenced by the HTML files is up to date.

## Running the Project Locally

1. Download or clone the project repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` in a browser, or use the **Live Server** extension.
4. Navigate through the site's sections using its navigation links.

If the project uses relative paths for images, stylesheets, scripts, or page links, keep the folder structure unchanged so those paths continue to work.
